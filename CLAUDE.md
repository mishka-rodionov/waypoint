# waypoint

Мобильная игра-тренажёр по спортивному ориентированию: выбор пути между КП, режим «память», разные дисциплины. «waypoint» — временное рабочее название. Концепция: [docs/concept.md](docs/concept.md).

Проект независим от экосистемы Competra (`~/projects/competra`): API Competra не используется.

## Правила работы

- Общение, комментарии к задачам и документация на русском. Идентификаторы в коде на английском.
- Коммитить и пушить только по явной просьбе пользователя, на каждое изменение отдельно.
- Собранное приложение на устройство или эмулятор не устанавливать: пользователь тестирует сам.
- Карты (`.omap`, `.ocd`, GPX, SRTM) в репозиторий не класть: права у авторов. Локально они лежат в игнорируемой папке `maps/` (обычно символьные ссылки).

## Стек

- Kotlin, Gradle (Kotlin DSL).
- Android: Jetpack Compose, Canvas для карты и рисования. Сначала только Android.
- Бэкенда нет, всё офлайн.

## Модули

- `:core`: чистый Kotlin, **без java.\* и Android** (чтобы позже перевести в Kotlin Multiplatform). Модель карты (`VectorMap`), растр проходимости (`TerrainGrid`, таблица `ISOM_2000`), рельеф (`ElevationGrid`; высоты горизонталей карты подбирает `ContourHeights`: сторона подъёма вдоль каждой горизонтали по SRTM, разница уровней соседей по лучам, целые уровни по остовному дереву с привязкой к SRTM в мёртвой зоне ±1,5 сечения), поиск пути A* с 16 направлениями (`Pathfinder`), оценка маршрута (`RouteEvaluator`; «твой выбор» — `CorridorRouter`: путь обязан пройти ворота вдоль нарисованной линии по порядку).
- Генератор карт (`waypoint.core.gen`, этап 3): рельеф из шума Перлина с искажением координат, сток (`Hydrology`: заполнение впадин, D8, водосбор) — озёра в глубоких впадинах, болота в мелких и в сырых низинах, ручьи по водосбору; растительность и открытые участки — пороги полей шума; тропы — A* между «точками интереса» (уже проложенные дешевле); площади и горизонтали — марширующие квадраты (`MarchingSquares`). Результат — `VectorMap` с кодами ISOM 2000, поэтому проходимость, оценка и отбор связок те же, что для OMAP.
- Дисциплины (`Discipline`, этап 4): кросс (`ISOM_2000`), вело и лыжи (`MTBO_ISOM`, `SKI_ISOM`: вне дорог и троп скорость 0, сеть шириной 5 м на растре — «граф» без отдельного графа), спринт (город 1:4000, `TownGenerator`). У дисциплины своя базовая скорость и крутизна Тоблера; движок оценки один.
- «По выбору» (`ScoreO`): точная динамика по подмножествам КП (n ≤ 16), штраф — очко за каждые начатые 5 с опоздания; матрица оптимальных времён между КП считается при сборке пака.
- `:tools`: JVM-импорт контента: OMAP (`OmapReader`, подложки не читаются), дистанции `.omap.courses` форка Mapper, горизонтали из шейпфайла, GPX, перевод координат карты ↔ UTM (`Georeferencing`, формула как в Mapper).
- `:sandbox`: десктоп-песочница этапа 0 на Swing: рисование маршрута мышью, разбор связки, слои «карта / проходимость / рельеф», режим «память».
- `:app` (Android, Jetpack Compose, minSdk 26): список связок пака, экран связки (карта тайлами, рисование пальцем, разбор), режимы «выбор пути» и «память». Зависит только от `:core`; карту и растры берёт из пака в `app/src/main/assets/packs/<карта>/`. Расчёт (оптимум сразу при открытии связки, разбор по «Готово») — на корутинах в `Dispatchers.Default`. Жесты описаны в `MapView` и в концепции («Рисование пальцем»).

Пак карты (`MapPack` в `:core`, сборка `BuildPack` в `:tools`): `meta.json` (сетка, рамка, уровни тайлов, масштаб, список дисциплин), `legs.json` / `legs-<дисциплина>.json` (связки с вариантами `LegExplorer`, посчитанными заранее), `scoreo-<дисциплина>.json` (задачи «по выбору» с матрицей времён и путей), `terrain.zbin` / `terrain-<дисциплина>.zbin` и общий `heights.zbin` (gzip; проходимость — байт-номер в палитре скоростей, высоты — 16-битные разности в сантиметрах), `tiles/<уровень>/<столбец>_<строка>.png` (256 px, уровень 0 — разрешение экспорта Mapper). Расширение растров не `.gz`: AGP распаковывает такие ассеты. Пак содержит чужую карту, поэтому `app/src/main/assets/packs/` в `.gitignore`.

Координаты в ядре — метры на местности в системе карты (x вправо, y вниз).

## Сборка и запуск

Gradle 9.8.1 (wrapper), Kotlin 2.4.21, JVM toolchain 17. Android: AGP 9.4.1, compileSdk 37, targetSdk 36, Compose BOM 2026.09.00 (как в competra-android); SDK — `sdk.dir` в `local.properties` (`~/Library/Android/sdk`).

```bash
./gradlew test                      # тесты (и юнит-тесты :app); тесты на настоящей карте пропускаются, если нет maps/
./gradlew :sandbox:run              # песочница: берёт первую .omap и .shp из maps/
./gradlew :sandbox:run --args="--map путь.omap --contours горизонтали.shp --gpx трек.gpx --interval 2.5"
./gradlew :sandbox:installDist      # затем sandbox/build/install/sandbox/bin/sandbox
./gradlew :tools:mineLegs -Pargs="--candidates 600 --count 40"   # отбор интересных связок → maps/<карта>.legs.json
./gradlew :tools:buildPack -Pargs="--title Мача"   # пак карты → app/src/main/assets/packs/<карта>/ (≈10 с)
./gradlew :tools:generatePack -Pargs="--seed 7"      # пак процедурной карты 2,5×2,5 км → packs/gen-7/ (≈20 с; --size, --relief, --green, --png, --disciplines)
./gradlew :tools:generatePack -Pargs="--type sprint --seed 3"   # пак спринтерского города 800×800 м, 1:4000 → packs/sprint-3/
./gradlew :app:assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk (пак надо собрать раньше)
```

Сгенерированная карта рисуется своим рендером `IsomRenderer` (цвета и толщины ISOM 2000 при 1:7500, штриховка болот, пунктир троп, линии севера). Приложение показывает все паки из `assets/packs/` и помнит последний выбранный.

Пак собирается из `maps/`: OMAP, шейпфайл SRTM, экспорт Mapper `<карта>.png` + `.pgw` и, если есть, `<карта>.legs.json`; в пак попадают отобранные связки и связки дистанций из `.omap.courses`. Тест `RealPackTest` проходит путь приложения на собранном паке (пропускается без пака).

Отбор связок (`LegExplorer`): оптимум, непохожие альтернативы (A* со штрафом на коридор уже найденных путей) и «бег напрямик»; интересность растёт, когда второй вариант медленнее оптимума на 3–12% и/или прямая заметно хуже (или перекрыта). Песочница показывает отобранные связки первыми в списке, а варианты — оранжевым пунктиром.

Фон карты рисует Mapper: экспорт всей карты в PNG с world-файлом, положенный рядом с картой под тем же именем (`maps/macha.png` + `maps/macha.pgw`) или переданный через `--background`. Без него песочница использует упрощённую отрисовку (`Layers.map`).

Снимок связки без окна (для проверки отрисовки): `JAVA_OPTS=-Djava.awt.headless=true sandbox/build/install/sandbox/bin/sandbox --snapshot out.png --leg 2 [--layer terrain|relief]` (`--leg -1` — вся карта, `--wiggle 40` — вместо прямой нарисовать змейку с таким размахом, `--mined 3` — отобранная связка вместо связки дистанции).
