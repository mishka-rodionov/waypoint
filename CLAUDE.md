# waypoint

Мобильная игра-тренажёр по спортивному ориентированию: выбор пути между КП, режим «память», разные дисциплины. «waypoint» — временное рабочее название. Концепция: [docs/concept.md](docs/concept.md).

Проект независим от экосистемы Competra (`~/projects/competra`): API Competra не используется.

## Правила работы

- Общение, комментарии к задачам и документация на русском. Идентификаторы в коде на английском.
- Коммитить и пушить только по явной просьбе пользователя, на каждое изменение отдельно.
- Собранное приложение на устройство или эмулятор не устанавливать: пользователь тестирует сам.
- Код не писать, пока пользователь не попросит: сейчас идёт этап концепции.

## Стек

- Kotlin, Gradle (Kotlin DSL).
- Android: Jetpack Compose, Canvas для карты и рисования. Сначала только Android.
- Бэкенда нет, всё офлайн.

## Структура модулей (планируемая)

- `:core`: чистый Kotlin, **без зависимостей от Android**. Модель карты, проходимость, рельеф, поиск пути, оценка маршрута, генератор. Тесты на JVM. Должен оставаться пригодным для перевода в Kotlin Multiplatform.
- `:tools`: консольная JVM-утилита для подготовки контента: импорт OMAP, восстановление рельефа, генерация карт, отбор связок, упаковка паков.
- `:app`: Android-приложение, зависит от `:core`.
